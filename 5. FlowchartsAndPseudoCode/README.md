# Flowchart and Pseudocode - README

# Introduction

Programming start karne se pehle hume problem ko samajhna aur plan banana hota hai.

Iske liye do important tools use hote hain:

1. **Flowchart**
2. **Pseudocode**

Ye dono programming logic ko easy banate hain.

---

# 1. What is a Flowchart?

Flowchart ek **diagram** hota hai jo program ka flow step-by-step show karta hai.

Simple words mein:

> Program ka graphical representation.

---

# Why Flowcharts are Important?

* Logic samajhne mein easy
* Errors jaldi identify hote hain
* Program planning easy hoti hai
* Beginners ke liye helpful

---

# 2. Common Flowchart Symbols

| Symbol        | Meaning        |
| ------------- | -------------- |
| Oval          | Start / End    |
| Rectangle     | Process        |
| Parallelogram | Input / Output |
| Diamond       | Decision       |
| Arrow         | Flow Direction |

---

# 3. Flowchart Symbols Explanation

---

## Start / End Symbol (Oval)

Program kaha start aur end hoga.

Example:

```text
 START
```

```text
 END
```

---

## Process Symbol (Rectangle)

Calculation ya processing ke liye.

Example:

```text
 sum = a + b
```

---

## Input / Output Symbol (Parallelogram)

Input lene aur output dikhane ke liye.

Example:

```text
 Enter Number
```

```text
 Print Result
```

---

## Decision Symbol (Diamond)

Condition checking ke liye.

Example:

```text
 number > 0 ?
```

# 5. What is Pseudocode?

Pseudocode ek **simple English-like language** hoti hai jo programming logic explain karti hai.

Ye actual programming language nahi hoti.

---

# Why Pseudocode is Important?

* Logic samajhne mein easy
* Coding se pehle planning hoti hai
* Any programming language mein convert kar sakte hain
* Beginners ke liye best

---

# 6. Rules of Pseudocode

1. Simple English use karo
2. Easy steps likho
3. Programming syntax follow karna zaroori nahi
4. Proper sequence maintain karo

---

# 7. Example of Pseudocode

## Problem:

Do numbers ka addition karo.

---

## Pseudocode

```text
START

INPUT A
INPUT B

SUM = A + B

PRINT SUM

END
```

---

# 8. Another Example

## Problem:

Check karo number even hai ya odd.

---

## Pseudocode

```text
START

INPUT NUMBER

IF NUMBER % 2 == 0
    PRINT "Even"
ELSE
    PRINT "Odd"

END
```

---

# 10. Difference Between Flowchart and Pseudocode

| Flowchart                 | Pseudocode                      |
| ------------------------- | ------------------------------- |
| Diagram form              | Text form                       |
| Graphical                 | English-like steps              |
| Symbols use hote hain     | Simple statements use hote hain |
| Visual understanding easy | Writing easy                    |
